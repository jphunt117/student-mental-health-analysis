# student-mental-health-analysis
An analysis on students mental health given different factors.

# Problem
Using a dataset that has various information about students, including gpa, sleep habits, time spent studying and more, I want to answer the following:
1. Can we predict a student's stress level given sleep habits, study time, gpa, etc.
2. Can we predict if a student suffers from depression given their lifestyle.

# Data
The dataset was retrieved from: https://www.kaggle.com/datasets/aldinwhyudii/student-depression-and-lifestyle-100k-data and contains the following information:
1. Student_ID
2. Age
3. Gender
4. Department
5. CGPA
6. Sleep_Duration
7. Study_Hours
8. Social_Media_Hours
9. Physical Activity
10. Stress_Level
11. Depression
